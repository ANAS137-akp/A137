دليل لغة A137 الشامل

1. هوية اللغة والبداية:
اسم اللغة: A137
البدء: !start-a137! | النهاية: !end!

2. إعدادات وتسمية تطبيق الويب:
webapp!اسم_التطبيق!

3. نظام الأشكال الهندسية والإحداثيات:
مربع/مستطيل: bg#HEX(عرض.طول) (مثل: bg#ff0000(5.5))
دائرة: bgo#HEX(عرض.طول) (مثل: bgo#00ff00(6.6))

4. نظام الطباعة والعرض:
إنجليزي: p'نص'#HEX أو p#رقم#
عربي: ن'نص'#HEX أو ن#رقم#

5. نظام المدخلات:
إنجليزي: uo1 = ask'أدخل القيمة:'
عربي: uo1 = س'أدخل القيمة:'

6. نظام الشروط الذكية والمنطق:
إنجليزي: if#uo1# == 'قيمة' -> ...
عربي: إ#uo1# == 'قيمة'o'بديل' -> ...
العكس: else -> ... أو إلا -> ...

7. نظام التفاعل واللمس (إنجليزي حصراً):
C.b1'نص الزر't.b1.gt

8. نظام بوابات الدفع (إنجليزي حصراً):
تجريبي: Fpay#المبلغ#'العملة'
حقيقي: pay#المبلغ#'العملة'#'رابط_الدفع'

9. ربط المكتبات البرمجية:
إنجليزي: pbs"رابط" | عربي: بمك"رابط"
