1. الهوية والبداية

• بداية الكود: !start-a137!
• نهاية الكود: !end!
• اسم وتصدير التطبيق: webapp!NAME!
• التعليقات البرمجية: @ النص يتم تجاهله

2. الأشكال الهندسية

• مستطيل/مربع: bg#HEX(عرض.طول)
• دائرة/شكل بيضاوي: bgo#HEX(عرض.طول)

3. الطباعة والعرض (Print)

• طباعة نص أو أرقام: p'Text'#HEX أو p#123#

4. المدخلات والمتغيرات (Ask)

• لاستقبال مدخلات المستخدم: uo1 = ask'الرسالة'

5. الأحداث والتفاعل (Touch/Click)

• ربط العناصر بالأحداث: C.[ID]'TEXT't.[ID].gt

6. الشروط والمنطق

• صيغة المقارنة النصية: *=* | الرقمية: #=#
• الدمج والاحتمالات باختصار: o'نص'
• الصيغة المباشرة والسريعة:
if#uo1# == 'help'o'دعم' -> p'أهلاً بك'#00ff00
