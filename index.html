A137 code IDE

دليل قواعد لغة A137 code

1. البداية وتسمية التطبيق

  • • بداية ونهاية الكود: !start-a137! وفي النهاية !end!
  • • اسم التطبيق: webapp!NAME!

2. خوارزميات الذكاء الاصطناعي (A137 AI)

  • • السطر الأول (شرط التكرار): if in.v 'الكلمة' 5t (البحث عن تكرار الكلمة 5 مرات في جميع المتغيرات المسجلة in.v).
  • • السطر الثاني (أمر الاستبدال): b'الكلمة المرمية' f'الكلمة البديلة' (حيث b تسبق الكلمة المُراد إزالتها، و f تسبق الكلمة البديلة).

3. الشروط والبدائل المتعددة (Logical IF / OR)

  • • دعم البدائل: if u1 = 'نص1' o u1 = 'نص2' (استخدام حرف o لدمج الاحتمالات المتعددة).

4. الأزرار والتفاعل

  • • زر مستمر: cp'TEXT'gt (ينفذ الكود البرمجي الذي تحته ولا يختفي).
  • • زر مخفي: cb'TEXT'gt (ينفذ الكود البرمجي الذي تحته ثم يختفي تلقائياً).
  • • التعليقات البرمجية: تبدأ بـ @ ويتم تجنبها عند توجيه الأحداث للسطر البرمجي التالي.

5. الواجهة وبوابات الدفع

  • • مستطيل / مربع: bg#HEX(عرض.طول)
  • • دائرة / بيضاوي: bgo#HEX(عرض.طول)
  • • طباعة نص ملون: p'TEXT'#HEX
  • • استقبال مدخلات: u1 = ask'Prompt:'
  • • دفع تجريبي: Fpay#AMOUNT#'CURRENCY'
  • • دفع حقيقي: URL.pay#AMOUNT#'CURRENCY' (يفتح في نافذة مستقلة لتفادي التعليق).
